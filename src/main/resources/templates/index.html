This web edition runs as a Spring Boot Progressive Web App on AWS Elastic Beanstalk. Every dungeon floor is procedurally generated and unique. The game is turn-based: the world only moves when you do.

How to Play

Use the keyboard to navigate the dungeon. Press N to start a new game, enter your name and character class, then descend into the dungeon.

  • Navigate with h j k l y u b n (vi-keys) or arrow keys
  • Press > to descend stairs (even-numbered floors have shops)
  • Press < to ascend stairs (floor 1 exits the dungeon)
  • Press e to eat food; , to pick up items
  • Press s to search for secret doors
  • Press W to wear armour; w to wield weapons
  • Press Q to quit the current game

Game Features

  • Procedurally generated dungeons — every run is unique
  • Six character classes: Fighter, Cave-man, Tourist, Wizard, Knight, Speleologist
  • Turn-based combat with monsters, traps and special rooms
  • Shops on even-numbered floors with food and merchandise
  • Vaults on odd-numbered floors with gold guarded by vault guards
  • Full inventory system: weapons, armour, rings, wands, potions, scrolls
  • Level memory — previously visited floors are remembered when you return
  • Progressive Web App — installable, works offline
  • DOM-grid rendering — every dungeon tile is a selectable HTML element
